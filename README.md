# Julien & Dynasties

Simulation de guilde d'aventuriers dans le comté d'Aurmont. Vous dirigez une maison de la Ligue des Lanternes : recrutez, équipez, envoyez quatre héros sous terre chaque semaine, et vivez avec ce qui remonte. Les morts sont définitives, les Annales retiennent tout.

Projet personnel, non commercial. Univers, noms, textes et visuels originaux, entièrement dessinés en code (aucune image, aucun fichier son).

## Jouer

Ouvrez `index.html` dans un navigateur (Chrome, Edge, Firefox). Aucune installation, aucun serveur.
La partie est sauvegardée automatiquement dans le navigateur. L'onglet Options donne un code de sauvegarde pour changer d'appareil.

## Contenu

**Visuels**
- Écran titre animé : lanternes qui s'envolent au-dessus de la ville.
- Hall de la guilde dessiné en direct : il grandit avec les installations, s'allume selon l'effectif, arbore vos couleurs et vos trophées.
- Descentes animées : couloirs, torches, héros et monstres dessinés, chiffres de dégâts, soins, coups critiques, conditions visibles (neige, brume, éboulis, spores).
- Portraits procéduraux pour chaque héros : visage, coiffure, équipement de classe, cicatrices, expression selon le moral.
- Carte du comté générée pour chaque partie.

**Jeu**
- Ligue de 32 guildes sur 4 divisions (Ardoise, Bronze, Argent, Couronne), 14 semaines par saison, montées et descentes, la Lanterne d'Or pour le champion.
- Coupe du Solstice : 32 guildes, élimination directe, 5 tours.
- Chaque semaine, choix entre une descente classique et une descente périlleuse.
- Combats simulés passe par passe : conditions, salles à événements, gardiens avec mécaniques propres.
- Héros : 6 classes, 16 traits actifs, motivation, peur et rêve personnels, niveaux, séquelles, hauts faits, amitiés, parenté avec les héros tombés, vieillissement, retraite.
- Mort permanente, tactiques Prudente / Équilibrée / Agressive, infirmerie et salle d'armes.
- Mécène avec un objectif par saison, contrats à renouveler ou négocier.
- Quêtes, marché des transferts, offres des guildes rivales, derbys.
- Annales écrites à partir des événements réels, mémorial, records, Gazette, Codex.
- Mode Ironman et musique synthétisée.

## Mettre à jour la version en ligne

Remplacez `index.html` et `README.md` dans votre dossier, puis dans le terminal :

```bash
git add .
git commit -m "Version finale"
git push
```

Vercel redéploie automatiquement en une vingtaine de secondes.
